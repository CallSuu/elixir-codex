# 엘릭서 코덱스 (Elixir Codex) 🧪

> "신비로운 연금술 가마솥에 나의 일상 습관과 영양제를 넣어, 전설의 비약을 연성하다"
> 일상 습관·영양제 인증을 재료 삼아 AI가 엘릭서를 연성하는 웰니스 덱빌딩 & 수집형 웹앱입니다.

---

## 📌 프로젝트 소개

**엘릭서 코덱스**는 고풍스러운 중세 판타지 세계관(NPC 늘해랑과 부상당한 용사의 건강 회복 스토리) 위에서, 실제 건강 습관과 영양제 섭취를 게임화한 서비스입니다.

일일/주간 퀘스트로 재료를 모으고, 실제 섭취한 영양제를 사진으로 인증하면 그날의 재료가 가마솥에 자동으로 모입니다. AI가 그 재료를 바탕으로 세상에 하나뿐인 엘릭서 카드를 연성해주고, 유저는 이걸 도감에 수집하며 성장합니다.

---

## 🛠 기술 스택

- **Backend**: Spring Boot 4.1(Framework 7), Java 17, Gradle
- **DB**: MySQL (JPA/Hibernate), 테스트는 H2 인메모리로 분리
- **인증**: Spring Security + JWT
- **AI**: OpenAI GPT-4o(텍스트 생성·영양제 인증 비전 분석), Stability AI(카드 아트 실시간 생성, 실패 시 사전 템플릿 폴백)
- **플랫폼**: Web App
- **배포**: 가비아 클라우드(Ubuntu) + systemd

## 🔑 핵심 기능

### 인증
회원가입 · 로그인 · 로그아웃 · 내 정보 조회

### 퀘스트
일일 퀘스트(자동 배정, 수동 완료 + Health 데이터 자동 판정, 완료 시 재료 카드 지급) · 주간 퀘스트(도메인 기반 자동 배정, 완료 시 Common 등급 + Rare~Epic 등급 재료 카드 2개 지급)

### 재료 · 영양제 인증
재료 인벤토리(확정된 15종 재료) · 가마솥 스택 조합(당일 인증 영양제 자동 편입) · 영양제 인증 사진 업로드(GPT-4o 비전으로 제품명·신뢰도 판정)

### 연금술 연성
GPT-4o 명칭·조언 문구 생성 · 카드 아트(사전 템플릿 매칭 + Stability AI 실시간 생성 폴백) · 등급 산정(점수제 + 확률 업그레이드 + 프리즘 레전더리) · 카드 수치형 스탯(4대 테마별 4종 확정) · 고정 레시피(정해진 재료 조합 시 확정 카드 + 과학적 성분 설명)

### 도감 · 마이페이지
도감 목록/상세 조회

### 온보딩 · 스페셜 엘릭서
온보딩 텍스트 AI 도메인 분류 · 스페셜 엘릭서 생성(최대 3개 제한)

### 출석체크
연속 출석 판정

## 💻 로컬 실행 방법

### 1. MySQL 준비

```sql
CREATE DATABASE elixir_codex;
```

### 2. 환경변수 설정

IntelliJ 실행 설정(`DemoApplication`)의 Environment variables에 아래 값을 추가합니다.

```
DB_USERNAME=본인_mysql_아이디
DB_PASSWORD=본인_mysql_비밀번호
OPENAI_API_KEY=본인_OpenAI_API_키
STABILITY_API_KEY=본인_Stability_AI_API_키
JWT_SECRET=32자_이상의_임의의_문자열
```

### 3. 실행

```
./gradlew bootRun
```

정상 실행되면 `http://localhost:8080`에서 서버가 동작합니다.

### 4. 테스트

```
./gradlew test
```

테스트는 실제 MySQL이 아닌 H2 인메모리 DB를 사용하도록 분리되어 있어, 개발용 데이터베이스에 영향을 주지 않습니다.
